# Call Sounds Required

Please add these sound files to `frontend/public/sounds/`:

1. **outgoing-call.mp3** - Sound for caller (ringing tone)
2. **incoming-call.mp3** - Sound for receiver (ringtone)
3. **call-end.mp3** - Sound when call ends
4. **call-connected.mp3** - Sound when call connects

You can download free sounds from:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/phone/
- Or use default browser notification sounds

For now, I'll create a placeholder that uses browser's default beep.
